# スマホで遊ぶ

スマホのブラウザから、写真カード作成・CPU対戦・友達とのQR対戦を利用できます。アプリストアやPWAのインストールは不要です。

## 別回線のスマホとQRで対戦する場合（公開モード）

通常の `start-game.bat`（localhost）はPC専用で、回線の違うスマホには届きません。以下で起動してください。

1. **`start-public-battle.bat` をダブルクリック**（または `node scripts\launch-game.mjs --public`）。初回はcloudflaredの取得のためインターネット接続が必要です。
2. 黒いウィンドウに `別回線スマホ用（HTTPS公開）: https://xxx.trycloudflare.com/` と表示されるまで待ちます。URLは起動ごとに変わります。
3. PCのブラウザでホームの「スマホで遊ぶ」を押します。QRには自動でこの公開URLが入ります（「別回線スマホ用の公開URLでQRを作成しました」と表示されます）。
4. スマホ（別回線・キャリア回線でも可）のカメラでQRを読み取り、Safari／Chromeで開きます。
5. PCもスマホも同じ公開URL側を開き、3体を編成して「友達と対戦」から同じ合言葉ルームに入ります。

注意：

- 公開URLはサーバー起動中のみ有効です。ウィンドウを閉じる・Ctrl+Cで無効になります。再起動するとURLが変わるのでQRを作り直してください。
- 部屋・写真・戦闘状態は従来どおりサーバーのメモリのみで、待機10分・終了後5分で破棄します。公開中も合言葉を知らない第三者は入室できませんが、URL自体は知った人が開ける一時公開です。遊び終わったらサーバーを停止してください。
- PCが `http://localhost:3000`、スマホが公開URLのように入口が違っても、同じサーバープロセスに届くので同じ合言葉で対戦できます。確実なのは双方とも公開URLを開く方法です。
- `cloudflared` がない環境では `npx` 経由で自動取得を試みます。取得に失敗した場合はローカル起動として続行し、QRは従来の案内になります。

## GitHubから開く場合（Pages設定が必要）

GitHubのソースコード画面やZIPを開くだけではゲームは動きません。リポジトリ所有者が **Settings → Pages → Source → GitHub Actions** を設定し、**Actions → Publish smartphone game → Run workflow** で作業ブランチを選んで実行してください。現在、接続アプリからの有効化は権限不足（403）で止まっており、まだ公開済みではありません。

公開が成功した場合のURLは `https://kenkyu0909.github.io/oreka-games/`。写真作成とCPU対戦用で、友達ルームは利用できません（Pagesは対戦用Node/WebSocketサーバーを動かせません）。写真は端末内で解析し、ゲームにはネタバレのカード図鑑や保存パックを含めません。

## PCからスマホへ

1. Arenaのポート3000のライブプレビューを開き、最新の画面へ再読み込みします。
2. ホームの「スマホで遊ぶ」を押します。
3. PCに表示されたQRコードをスマホのカメラで読み取ります。
4. スマホの最新版Safari／ChromeでURLを開きます。
5. 「写真からカードを作る」で自分の写真を選び、名前を入れて「この写真でカードを生成」。3枚を編成して対戦します。すぐ試す場合は編成画面の「サンプル3体をセット」から。

QRを読み取れない場合は「コピー」でURLをスマホに送ってください。自動コピーが拒否された場合はURL欄が選択されるので、手動でコピーできます。Web Share対応端末では「URLを共有する」も表示します。

すでにスマホでArenaを使っている場合は、ライブプレビューを新しいタブで開いてそのまま遊べます。同じスマホ上のQRを再撮影する必要はありません。

## 何が共有されるか

- QR/コピー/共有は、今開いているゲームのHTTPSのゲーム入口だけです。Pagesでは `/oreka-games/` を保持します。
- 写真・編成・ルームコード・復帰トークン・URL内の認証情報やクエリは含めません。
- QRは端末内のライブラリで作成し、外部QRサービスには送りません。
- PCのカードや編成はスマホへ自動転送されません。スマホで写真を選び直すかサンプルを使用します。
- 通常サーバーの友達対戦では、双方が同じ入口URLを開き、チームを編成して合言葉ルームに参加します。ゲーム内の対戦相手には写真を共有します。

## 制限・開けないとき

- **Arenaプレビューはサーバー起動中だけ使えるお試し用です。** Arenaセッション/サーバー停止でアクセスできなくなったり、プレビューURLが変わることがあります。
- 接続に失敗したらサーバーの起動状態とArena側のプレビュー共有・アクセス設定を確認してください。別端末の認証や到達性は本作業環境では確認できません。
- `localhost`・`127.0.0.1` はスマホ自身を指すため、PCで見ているゲームへ接続するURLではありません。案内画面ではQRを作らず、HTTPSプレビューを開くよう表示します。
- 写真解析にはWeb Cryptoを使用します。スマホからLANのHTTPアドレスで開く場合は動作しないので、HTTPSのプレビューを使ってください。非HTTPS時の解析失敗は日本語で案内します。
- 写真はJPEG/PNG、12MiB・2,400万画素以下。HEICはJPEG/PNGへ変換してください。変換・圧縮・縮小により解析特徴、能力、技が変わることがあります。強さを調整したPNGは原本を使ってください。
- 縦持ちが基本です。横持ち・高さの低い画面はスクロールで操作します。スマホのノッチ用余白を設けています。
- 対戦中に別アプリに移動するとOSが通信を止める場合があります。オンライン戦は90秒以内の復帰を試みますが、長時間のバックグラウンド動作は保証しません。
- サンプル/CPU戦は画像の解析と戦闘を端末内で行います。ただし画面の読み込みにはサーバーへの接続が必要で、オフライン対応を保証するものではありません。

## 確認したこと / 未確認

- QRを実デコードして共有先URLを検証。URLからルーム情報等を除外、コピー権限拒否時の手動コピー、共有キャンセル/権限拒否を検査。
- ChromiumのiPhone 13/Pixel 7相当（画面・UA・タッチ）で写真選択、カード生成、技選択、交代、縦横切替を検査。文字入力の16px化とヘッダー操作44px化を確認。
- 既存のCPU/オンライン同期/再接続/レア技/PNG保存も回帰テスト。
- **実機Safari/Android Chrome、OSの写真アプリや共有アプリ、別端末から実際のArenaプレビューへの接続は未検証です。** iPhone相当のエミュレーションはSafari/WebKitの実機検証ではありません。
