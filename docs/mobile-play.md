# スマホでプレビューを試す（0.7.1）

今回は「まず今のゲームをスマホで試す」ための対応です。アプリストアへの公開・PWAインストール・常設サーバーの公開ではありません。

## PCからスマホへ

1. Arenaのポート3000のライブプレビューを開き、最新の画面へ再読み込みします。
2. ホームの「スマホで遊ぶ」を押します。
3. PCに表示されたQRコードをスマホのカメラで読み取ります。
4. スマホの最新版Safari／ChromeでURLを開きます。
5. 「デュエルを始める」でサンプルCPU戦、または「写真からカードを作る」で自分の写真を選びます。

QRを読み取れない場合は「コピー」でURLをスマホに送ってください。自動コピーが拒否された場合はURL欄が選択されるので、手動でコピーできます。Web Share対応端末では「URLを共有する」も表示します。

すでにスマホでArenaを使っている場合は、ライブプレビューを新しいタブで開いてそのまま遊べます。同じスマホ上のQRを再撮影する必要はありません。

## 何が共有されるか

- QR/コピー/共有は、今開いているゲームのHTTPSオリジンの入口 `/` だけです。
- 写真・編成・ルームコード・復帰トークン・URL内の認証情報やクエリは含めません。
- QRは端末内のライブラリで作成し、外部QRサービスには送りません。
- PCのカードや編成はスマホへ自動転送されません。スマホで写真を選び直すかサンプルを使用します。
- 友達対戦では、双方が同じ入口URLを開き、チームを編成して合言葉ルームに参加します。ゲーム内の対戦相手には写真を共有します。

## 制限・開けないとき

- **サーバー起動中だけ使えるお試し用です。** Arenaセッション/サーバー停止でアクセスできなくなったり、プレビューURLが変わることがあります。
- 接続に失敗したらサーバーの起動状態とArena側のプレビュー共有・アクセス設定を確認してください。別端末の認証や到達性は本作業環境では確認できません。
- `localhost`・`127.0.0.1` はスマホ自身を指すため、PCで見ているゲームへ接続するURLではありません。案内画面ではQRを作らず、HTTPSプレビューを開くよう表示します。
- 写真解析にはWeb Cryptoを使用します。スマホからLANのHTTPアドレスで開く場合は動作しないので、HTTPSのプレビューを使ってください。非HTTPS時の解析失敗は日本語で案内します。
- 写真はJPEG/PNG、12MiB・2,400万画素以下。HEICはJPEG/PNGへ変換してください。変換・圧縮・縮小により解析特徴、能力、技が変わることがあります。強さを調整したPNGは原本を使ってください。
- 縦持ちが基本です。横持ち・高さの低い画面はスクロールで操作します。スマホのノッチ用余白を設けています。
- 対戦中に別アプリに移動するとOSが通信を止める場合があります。オンライン戦は90秒以内の復帰を試みますが、長時間のバックグラウンド動作は保証しません。
- サンプル/CPU戦は画像の解析と戦闘を端末内で行います。ただし画面の読み込みにはサーバーへの接続が必要で、オフライン対応を保証するものではありません。

## 確認したこと / 未確認

- QRを実デコードして共有先URLを検証。URLからルーム情報等を除外、コピー権限拒否時の手動コピー、共有キャンセル/権限拒否を検査。
- ChromiumのiPhone 13/Pixel 7相当（画面・UA・タッチ）で写真選択、カード生成、技選択、交代、縦横切替を検査。文字入力の16px化とヘッダー操作44px化を確認。
- 既存のCPU/オンライン同期/再接続/レア技/PNG保存も回帰テスト。
- **実機Safari/Android Chrome、OSの写真アプリや共有アプリ、別端末から実際のArenaプレビューへの接続は未検証です。** iPhone相当のエミュレーションはSafari/WebKitの実機検証ではありません。
