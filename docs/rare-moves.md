# レア技20種 — photo-v3 / 0.7

通常48技に追加する強力な技。約5%の写真特徴セットに1技だけ入り、4枠目を置き換えます。同じ写真・同じルール版なら結果は固定。箔加工とは無関係です。各属性3技＋無属性2技、全てPP2〜3。数値は初期調整値です。

威力は1打あたり。適性は本人の攻撃能力が高い方に確定。吸収は実ダメージ×率×(0.75＋回復力×0.005)、回復は通常量×倍率、状態異常の付与率は耐性で軽減されます。
